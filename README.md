### About

Physics and EECS (AI track) double major at National Tsing Hua University, Taiwan, applying for PhD entry in 2027.
At the HMI Lab I build generative decoders that reconstruct 3D spatial structure from fMRI. My other work is on
predictive coding, associative memory and sampling-based inference. In 2026 I visited UCLA Samueli through the
Taiwan Global Pathfinders program.

### Open source

I fix correctness defects in GPU, parallel computing, 3D and scientific Python libraries: wrong results, crashes and
concurrency bugs. Each pull request carries a reproduction a maintainer can run and a test that fails before the fix
and passes after it.

### Selected work

- [X-Ray](https://github.com/Arthur031221/X-Ray), chest X-ray pathology classification trained on one demographic subgroup and evaluated across all five, DenseNet121 against Xception
- [NSF-HDR](https://github.com/Arthur031221/NSF-HDR), team entry for the 2025 NSF HDR anomaly detection challenge, all three tracks
- [quantum-allosteric-scanner](https://github.com/Arthur031221/quantum-allosteric-scanner), continuous time quantum walk prediction of allosteric sites from a single unbound protein structure
